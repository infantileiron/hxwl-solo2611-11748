# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、发起时的校准版本、运行租约、分析结果、导出文件及复核决定。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、校准导入、运行、复核和报表分发动作。
- `calibration_state` 单行记录当前校准版本，导入时作为串行化锁。
- `calibration_batches` 每次校准导入的名称、指纹、版本和应用/忽略条数。
- `calibration_entries` 追加式校准明细，保留每个版本起生效的探针与交接日期偏差，供运行按发起版本回溯。
